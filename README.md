A one-line joke about working beside AI coding agents, written by a small
deterministic program for the make.fun bounty
[the-joke-about-the-demo-20261123-0112](https://make.fun/competitions/the-joke-about-the-demo-20261123-0112).

`main.ts` (Node 22) writes the joke to `/output/entry.txt`:

> During the demo, my AI coding agent apologised for the bug, fixed it, apologised for the fix, then reintroduced the bug out of politeness.

Run it with `node main.ts`. No network, no randomness — every run writes the
same 138 characters.
